📱 QR Scan Attendance System
📌 Overview

The QR Scan Attendance System is a simple project used to mark attendance using QR codes. Instead of taking attendance manually, students scan a QR code and their attendance is recorded automatically. This system saves time and avoids mistakes.

🎯 Purpose

To make attendance easy and fast

To avoid manual work

To reduce fake attendance

To store attendance records safely

⚙️ How It Works

A QR code is generated for attendance.

The QR code is shown to students.

Students scan the QR code using a camera.

Attendance is saved with date and time.

🧩 Features

Easy to use

Fast attendance marking

Automatic record storage

Reduces errors

🛠 Technologies Used

Python

QR Code library

OpenCV

CSV file for storage

📚 Conclusion

The QR Scan Attendance System is a simple and useful project that helps in managing attendance efficiently using QR codes.
